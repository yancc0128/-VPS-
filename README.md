# VPS 半自动化部署助手

一个面向 macOS 与 Windows 的 VPS 半自动化部署工具，专注于简化远程服务器初始化、代理环境配置以及常用服务部署流程。

## 项目功能

- 一键初始化 VPS 基础环境
- 自动安装常用运行依赖
- 快速配置代理与网络环境
- 支持远程 SSH 部署流程
- 简化服务器首次配置步骤
- 减少手动命令操作与重复配置
- 提供更统一的部署体验
- 一键自愈修复（Claude / DNS / IPv6 / BBR / Xray / 防火墙）
- 可选的 AI 诊断解读（默认关闭，可随时跳过）

## AI 诊断解读（可选）

桌面端提供一个**默认关闭、可随时跳过**的 AI 解读功能：把自愈/诊断的原始输出
转成自然语言的结论与排错建议。

- **可选且可跳过**：不配置也能完整完成部署；界面中为默认折叠的卡片，提供「暂不配置」按钮，可空密钥保存、以后再补。
- **发送前脱敏**：IP、域名、密钥、UUID、订阅链接等会被替换为占位符后才发送，绝不发送 SSH 密码、sudo 密码或主机指纹。
- **密钥只在本机**：API Key 保存在本机用户数据目录（`0600` 权限），不会回传到界面层，也不会写入日志。
- **只解读、不执行**：AI 仅生成文字分析，不会生成或执行任何远程命令；接口不可用 / 未配置 / 超时会自动回退到本地规则总结。
- 默认对接 DeepSeek（OpenAI 兼容接口，`https://api.deepseek.com`，模型 `deepseek-chat`），接口地址与模型可在设置中修改。

## 安全与隐私

- **SSH 主机密钥校验（TOFU）**：首次连接记录指纹并持久化，之后每次比对，指纹不一致时**拒绝连接**并提示，可防中间人攻击；CLI 支持 `--host-fingerprint` 预校验。
- **远程脚本防注入**：下发到 VPS 的配置以 base64 传输、远程解码写入，协议名走白名单，避免命令注入与 heredoc 提前结束。
- **本地优先**：VPS IP、SSH/sudo 密码、私钥、节点配置、订阅链接均不上传；敏感字段在界面默认隐藏。
- **严格 CSP**：渲染层禁用对外网络连接（`connect-src 'none'`），所有外发请求只在主进程按需发起。
