辅助命令

建立或确认长期管理员账号

推荐使用普通管理员账号加 sudo，不推荐长期使用 root 密码登录。

sudo adduser myadmin
sudo usermod -aG sudo myadmin

ssh myadmin@VPS_IP
sudo whoami

如果 sudo whoami 输出 root，说明长期管理员账号可用。

第 2 步

选择部署身份

推荐创建 App 专用临时部署账号并切换过去部署；如果你更重视简单流程，也可以继续使用已验证的长期管理员账号。

sudo adduser appdeploy
sudo usermod -aG sudo appdeploy
