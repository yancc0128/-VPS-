第 1 步

VPS SSH 连接与长期管理员验证

未验证

长期账号用于以后维护 VPS。桌面版会先在本机测试 SSH 登录和 sudo whoami，确认输出为 root 后才继续后续部署。

密码只保存在当前页面内存中。Web 预览版不能直接 SSH，请使用下方命令手动验证。

辅助命令

建立或确认长期管理员账号

推荐使用普通管理员账号加 sudo，不推荐长期使用 root 密码登录。

sudo adduser myadmin
sudo usermod -aG sudo myadmin

ssh myadmin@VPS_IP
sudo whoami

如果 sudo whoami 输出 root，说明长期管理员账号可用。

第 2 步

固定安全协议

当前不提供协议选择，统一使用更安全、抗封锁且兼顾性能的固定方案：

Xray-core + VLESS + REALITY + XTLS Vision + uTLS
用于优先保证安全、抗识别、防封锁和稳定加速。客户端会按这一套协议生成配置。
